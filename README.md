# Steam 版孢子（Spore）太空阶段修改器

&gt; 谨献给我的小宇航员 · v1.0

这是一个爸爸写给儿子的修改器。

儿子今年五岁半，迷上了《孢子》。他捏的小生物爬上了陆地、建起了部落、创立了城市，终于盼到了太空阶段——然后他的飞船第一次被打爆。他愣了几秒钟，哇一声哭了出来。

那天晚上他睡着以后，我开始自学 Cheat Engine。一个三十多岁、白天还要上班的人，对着满屏的十六进制，从"指针链"三个字完全看不懂，到一点点摸到门路。游戏每次重启一次，好不容易找到的指针就整条作废，只能从头再来（当然后来我知道有技巧可以快速提取稳定的指针链）。中间崩溃过的次数（比如航程，可视距离都是使用非正常手段才获取的指针），比他被击落的飞船还多。

但只要想到他发现新恒星时发亮的眼睛，就觉得这些深夜都值了。

现在，他的飞船不会再被打爆了。他可以慢慢飞，飞到任何他想去的地方，看每一颗他想看的星星。这大概就是爸爸能给的、最小的超能力。

如果你也是一位陪孩子玩游戏的家长，希望这个修改器也能帮到你们。愿每个孩子的宇宙，都又大又安全。

## ✨ 功能一览

| 功能 | 操作方式 | 说明 |
|---|---|---|
| ❤️ 生命 | 输入数值，拨动开关即锁定 | 太空战斗再也不怕翻车 |
| ⚡ 能量 | 同上 | 与生命共用锁定机制 |
| 💰 金钱 | 输入数值，回车 | 立即到账 |
| 🚀 航程 | 输入数值，回车 | 仅对初始引擎生效，升级引擎后失效 |
| 🔭 可视范围 | 输入数值，回车 | 仅对初始引擎生效，升级引擎后失效 |

**锁定机制说明：**

- 锁定值留空时，锁定的是**拨动开关那一刻**游戏里的当前数值
- 锁定状态下修改输入框、敲回车，即可**换锁新值**，无需关开关
- 开关管"锁不锁"，回车管"锁哪个数"

## 🚀 使用方法

1. 启动 Steam 版《孢子》，进入**太空阶段**（生命/能量/金钱在全阶段可用）
2. 运行修改器（`python spore_trainer.py`，或下载 Releases 里的打包版直接双击）
3. 状态栏显示"已附加到游戏"后即可使用
   - 在输入框填写数值，**回车** = 立即写入一次（不锁定）
   - 拨动**锁定开关** = 持续锁定该值
4. 关闭修改器前无需取消锁定，直接关即可

**提示：** 修改器运行期间游戏若崩溃/重启/读档切阶段，修改器会自动检测并重连，无需重启。

## 🧰 运行环境

- Windows 10 / 11
- Steam **正版**《孢子》（Spore）— 其他版本未做验证
- 直接运行：`Python 3.10+`，依赖 `pymem`
- 零安装版：见 Releases（单文件 exe，无需 Python）

```bash
pip install pymem
python spore_trainer.py
```
